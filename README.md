# Task 3: SQL Basics – Filtering, Sorting & Aggregations

## Dataset
Superstore (CSV)

## Tool Used
SQLite Online

## Queries Performed
- SELECT and LIMIT to preview data
- WHERE clause for filtering records
- ORDER BY to sort sales data
- GROUP BY with SUM and AVG for aggregation
- HAVING to filter grouped results
- BETWEEN for date range analysis
- LIKE for pattern matching

## Outcome
This task helped me understand basic SQL operations and gain confidence in querying structured datasets.
